## About Toolio

Toolio Automation helps creators organize and run repetitive media workflows from one Windows desktop application. Version 1.0.8 introduces the production-ready Flow Image, Flow Video, and Gemini TTS workflows alongside Toolio's existing media utilities.

> [!IMPORTANT]
> Toolio is an automation assistant. Google accounts, generation credits, API credits, and third-party subscriptions are not included. Users must supply and manage the accounts and credits required by each supported service.

## Available in 1.0.8

- **Flow Image** — create image batches from prompts and references with parallel jobs, progress tracking, saved work, and output management.
- **Flow Video** — create and manage video batches using Text/Frames, Ingredients, and Scene Chain workflows.
- **Gemini TTS** — split long scripts and generate voice parts in batches with voice, style, pace, accent, and audio controls.
- **Google Accounts Manager** — manage multiple supported Google accounts, check readiness, and view available credit information where supported.
- **Toolio Flow Helper** — optional Chrome extension for a lighter Flow connection path and fewer browser-related failures.
- **CapCut Automator** — prepare and synchronize supported media workflows with CapCut projects.
- **Whiteboard Animator** — create configurable whiteboard-style animation workflows.
- **Sequence Checker & Shifter** — find sequence gaps and reorganize numbered media files.
- **Prompt Cleaner** — clean repeated patterns and unwanted formatting from prompt batches.

## Platform

- Windows desktop application built with Electron.
- Dark and light themes.
- Secure sign-in and device access management.
- Recoverable saved work for generation workflows.
- Managed updates with integrity checks and safe restart handling.
